# Sarath S — Personal Portfolio

A responsive, single-page portfolio website built with pure HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — navigation, scroll animation and project modals
- `assets/resume.pdf` — place your latest CV here
- `assets/profile.jpg` — optional profile photo
- `assets/projects/` — optional project images

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a new public repository, for example `sarath-portfolio`.
2. Upload all files while preserving the folder structure.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
7. Your site will normally be available at:
   `https://YOUR-USERNAME.github.io/sarath-portfolio/`

## Before publishing
- Replace `assets/resume.pdf` with your actual latest CV.
- If you want a photo, add `assets/profile.jpg` and we can add it to the hero.
- Replace/add GitHub project links when your project repositories are ready.
- Review email, LinkedIn and project descriptions.
